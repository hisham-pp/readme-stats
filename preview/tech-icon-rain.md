## Parameters

| Parameter     | Type     | Default     | Description                                                            |
| ------------- | -------- | ----------- | ---------------------------------------------------------------------- |
| `techs`       | `string` | _All techs_ | Comma-separated list of technology keys falling in the background rain |
| `name`        | `string` | _None_      | Main title text displayed in the center of the banner                  |
| `description` | `string` | _None_      | Subtitle / description paragraph below the title                       |
| `width`       | `number` | `850`       | Banner width in pixels                                                 |
| `height`      | `number` | `300`       | Banner height in pixels                                                |
| `theme`       | `string` | `brand`     | Color palette of icons: `brand`, `dark`, `light`, or `bg`              |
| `color`       | `string` | `#FFFFFF`   | Hex color code for foreground text                                     |
| `bgcolor`     | `string` | _Auto_      | Background color (or `transparent` for transparent background)         |
| `fontSize`    | `number` | `54`        | Font size for the main name heading                                    |
