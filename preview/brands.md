# Available Technologies & Brands Directory

> **Quick Links:** [Single Icon API](./icon.md) | [Single Badge API](./badge.md) | [Badge Marquee](./badge-marquee.md) | [Icon Marquee](./icon-marquee.md)

This directory lists all **239 supported technologies and brands** available across:

- **Single Icon API**: `/api/icon?name=<id>`
- **Single Badge API**: `/api/badge?name=<id>`
- **Marquee Generators**: `/api/tech-badge-marquee?techs=<id1>,<id2>` & `/api/tech-icon-marquee?techs=<id1>,<id2>`
- **Rainfall Banner**: `/api/tech-icon-rain`

You can query any technology using its **Query Key (`id`)** or its **Display Name** (case-insensitive).
