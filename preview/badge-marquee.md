---

## Parameters

| Parameter | Type     | Default     | Description                                                                                        |
| --------- | -------- | ----------- | -------------------------------------------------------------------------------------------------- |
| `techs`   | `string` | _All techs_ | Comma-separated list of technology keys to display in the marquee (e.g. `react,nextjs,typescript`) |
| `width`   | `number` | `850`       | SVG viewbox width in pixels                                                                        |
